# 발향부 설계 — 서보 + 향수 펌프 공병 (원액 분사)

> 확정 방향: 유화제/초음파 폐기 → 리필 공병에 아로마 원액 → 서보가 펌프 헤드를 눌러 미스트 분사
> 핵심 장점: 1회 분사 = 정량(0.05~0.1mL)이라 "분사 횟수"가 곧 발향량 → 제어가 이산적이고 깔끔

---

## 1. 전체 구조

```
        ┌─ 서보 혼 + 누름 레버 ─┐
        │      ▼ (3~5mm 스트로크)
   ┌────┴────┐
   │ 펌프 헤드│ ← 노즐 (스월 노즐이 미스트 생성 — 절대 제거 금지)
   ├─────────┤
   │  스템    │
   │ ┌─────┐ │
   │ │원액  │ │ ← 트래블용 리필 공병 (5~10mL)
   │ │     │ │
   │ └─────┘ │
   └─────────┘
   [공병 홀더]  ← 3D프린팅, 공병 통째 교체 = 카트리지 교체
```

동작: ESP32 → 서보 PWM → 레버가 펌프 헤드를 수직으로 누름 → 1회 정량 분사 → 서보 복귀

## 2. BOM

| 부품 | 스펙 | 수량 | 예상가 | 비고 |
|---|---|---|---|---|
| 서보모터 | **MG996R** (10kg·cm, 금속기어) | 향당 1 | ~7천원 | SG90은 힘 부족(경계선) — 아래 3절 |
| 리필 공병 | 펌프식 5~10mL | 향당 1+예비 | ~2천원 | 다이소/올리브영. 같은 모델로 통일(누름력 편차 방지) |
| 공병 홀더 | 3D프린팅 | 향당 1 | - | 공병 몸통 고정 + 서보 마운트 일체형 |
| 서보 전원 | 5V 3A 이상 (기존 5V 라인 분기) | 1 | - | ESP32 3.3V에서 절대 금지 |
| 전해 커패시터 | 470~1000µF / 10V | 1 | ~500원 | 서보 전원단 — 스톨 전류 스파이크 흡수 |
| 아로마 원액 | 수용성 아님, 그냥 원액 OK | 향당 | - | 에탄올 베이스 제품만 피할 것 (BME688 간섭) |

D4184 MOSFET은 발향부에서 빠짐 (서보는 PWM 신호선 직결).

## 3. 기구 설계

### 힘 계산
- 향수 펌프 누름력: 실측 필요하나 통상 **15~30N**, 스트로크 3~5mm
- MG996R 토크 10kg·cm = 레버 암 2cm 기준 **~49N** → 여유율 1.6배 이상 확보
- SG90(1.8kg·cm)은 암 1cm에서 ~18N으로 경계선 — 뻑뻑한 펌프면 기어 파손. 예비로만

### 누름 방식: 레버식 추천
```
서보 혼 ──── 레버(팔 길이 2cm) ──── 누름판
                                      ▼
                                  펌프 헤드
```
- 캠 방식보다 레버가 3D프린팅 오차에 관대하고 정렬이 쉬움
- 누름판은 펌프 헤드보다 넓게 (편심 누름 → 스템 휨 방지)
- 서보 각도: 대기 0° → 분사 ~40° (스트로크 5mm 확보 각도는 조립 후 캘리브레이션)
- 홀더에 공병 어깨를 잡는 턱 필수 — 누를 때 공병이 아래로 밀리면 스트로크 손실

### 노즐 방향
- 분사 방향: 수평~상향 15° (미스트가 위로 퍼지며 기류에 실림)
- **BME688 와드와 최소 50cm 이격 + 팬 하류 배치** — 원액 미스트가 센서에 직격하면 판독 포화

## 4. 전기 설계

```
5V 3A ─┬─ MG996R VCC   (커패시터 470µF 병렬)
       └─ (기존 부하)
ESP32 GPIO(예: 18) ─── MG996R 신호선 (50Hz PWM)
GND 공통 ─── ESP32 + 서보 + 전원
```
- 서보 스톨 전류 ~2.5A 순간 피크 → 커패시터 없으면 ESP32 브라운아웃 리셋 위험
- 멀티 카트리지(서보 N개) 시: **동시 구동 금지, 순차 분사**로 피크 전류 제한

## 5. 제어 로직 (ESP32)

```cpp
// 의사코드
const int SPRAY_ANGLE = 40, REST_ANGLE = 0;
const int PRESS_MS = 300, RELEASE_MS = 400;

void spray(int servo_idx, int count) {
  for (int i = 0; i < count; i++) {
    servo[servo_idx].write(SPRAY_ANGLE);  delay(PRESS_MS);
    servo[servo_idx].write(REST_ANGLE);   delay(RELEASE_MS);
  }
  servo[servo_idx].detach();  // 대기 중 떨림/전류 차단
}
```

발향량 제어 = 분사 횟수 매핑 (PWM 듀티 불필요):
| 목표 강도 | 분사 횟수 |
|---|---|
| 약 | 1회 |
| 중 | 2회 |
| 강 | 3~4회 |

### 폐루프 연동 규칙
1. 트리거는 반드시 `inference`의 **`label_voted` + `stable: true`** 조합만 사용 (raw 라벨 금지 — 투표 버퍼가 노이즈 거른 뒤에만 분사)
2. 시분할 유지: **분사 → 대기(확산 2~3분) → 센싱** 사이클. 분사 직후 판독은 무시 창(mute window)으로 버림
3. 히스테리시스: 목표 향 감지 상태에서 재분사 금지, voted 라벨이 Air로 복귀 후 일정 시간 지나야 재분사 허용
4. 안전 상한: 시간당 최대 분사 횟수 캡 (원액 과다 분사 = 냄새 공해 + BME688 장기 포화)

## 6. 멀티 카트리지 확장

- 홀더를 레일 형태로 N슬롯 설계, 슬롯당 서보+공병 1세트 (이동식 셔틀 없음 — 폐기안 재도입 금지)
- 혼합 발향 = 두 슬롯 순차 분사 (예: Woody 2회 + Citrus 1회 = 2:1 블렌드)
- ESP32 PWM 채널 여유 충분 (LEDC 16채널), 서보 신호선만 GPIO 추가

## 7. 테스트 플랜

| # | 테스트 | 방법 | 통과 기준 |
|---|---|---|---|
| S1 | 정량성 | 공병 무게 측정 → 20회 분사 → 재측정 | 회당 분사량 편차 ±20% 이내 |
| S2 | 기구 내구 | 연속 200회 분사 | 서보 과열/기어 이상 없음, 스트로크 유지 |
| S3 | 전원 안정 | 분사 중 ESP32 리셋 모니터 | 브라운아웃 0회 |
| S4 | 확산 시간 | 분사 → BME688 반응까지 시간 측정 (거리별) | 제어 루프의 대기 시간 파라미터 확정 |
| S5 | 센서 회복 | 분사 중지 후 Air 복귀 시간 | 히스테리시스 값 확정 |
| S6 | 폐루프 통합 | "Air 감지 → 자동 분사 → 향 감지 → 정지" 풀 시나리오 | 오분사/과분사 없이 3회 연속 성공 |

### 예상 삽질 포인트
- 분사가 약함 → 스트로크 부족. 서보 각도 늘리거나 레버비 조정
- 서보가 웅웅거리며 못 누름 → 토크 부족 or 공병이 밀림. 홀더 턱 확인
- 몇 회 후 분사량 감소 → 펌프에 공기 유입(프라이밍 풀림). 대기 각도에서 헤드가 살짝 눌린 상태 유지되지 않게 0° 재확인
- BME688이 계속 포화 → 이격 거리/팬 배치 재조정, mute window 연장
