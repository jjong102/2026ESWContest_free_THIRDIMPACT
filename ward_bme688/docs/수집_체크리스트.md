# BME688 향 재수집 체크리스트

목표 클래스: **Air / Good / Bad** (Citrus·Floral·Woody는 Good 한 버킷)

Bad 소스: 담배, 종이 탄냄새, 커피(음식물 대용)  
제품 스토리상 Bad 핵심: 담배·탄종이

하드웨어: ESP32 Feather + BME688 Development Kit

---

## 공통 규칙

- 세션 시작/끝 **Air purge 5~10분** (창·팬). 잔향 느껴지면 그 세션 **폐기**
- 샘플은 **컵/지퍼백**에만, 센서에 직접 문지르지 말기
- 한 세션 = **한 클래스·한 소스**만
- 같은 세션이 train/test에 안 섞이게 **세션 ID 기록**
- HP는 가능하면 **2개**로 동일 프로토콜 반복 후 비교
- 최소 **3 set** (다른 날·다른 시간대)

---

## 세션마다 적을 메모 (한 줄)

```
세션ID / 날짜·시각 / HP / 온도·습도 / 소스 / 거리 / 이상유무
```

예: `B02 / 9-10 16:20 / HP3 / 26°C 48% / 탄종이 식힘 / 15cm / OK`

## HP 비교

| HP | Set1 | Set2 | Set3 | 비고 |
|---|---|---|---|---|
| HP-A (현재/기본) | ☐ | ☐ | ☐ | |
| HP-B (대비 큰 후보) | ☐ | ☐ | ☐ | 중·고온 step 늘린 쪽 권장 |

동일 프로토콜로 두 HP를 돌린 뒤 AI-Studio/학습에서 비교.

## 균형 목표

| 클래스 | 목표 |
|---|---|
| Air | Good·Bad와 **비슷한 총량** (Air만 과다 X) |
| Good | 시트러스·플로럴·우디 **세션 수 비슷** |
| Bad | 담배·탄종이·커피 **세션 수 비슷** (스토리 핵심은 담배·탄종이) |

---

## 학습 전 Go/No-Go

- [ ] 클래스당 세션 ≥ 3 (다른 날)
- [ ] purge 실패한 세션 제외
- [ ] HP 후보 2개 각각 동일 set 수집
- [ ] **3클래스(Air/Good/Bad)**로만 학습 — Citrus/Floral/Woody 분리 안 함
- [ ] confusion에서 **Bad→Good / Good→Bad**가 줄었는지 확인 후 export
- [ ] Woody recall=0 같은 붕괴면 export 금지, HP/수집부터 재검토

---

## 런타임 매핑 (참고)

- `Bad` → 팬/필터 **ON**
- `Air`, `Good` → **OFF**
- confidence 낮으면 이전 상태 유지 또는 OFF
