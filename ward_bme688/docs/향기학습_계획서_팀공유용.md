# 향기 학습, AI-Studio 없이 직접 만듭니다 (팀 공유용)

작성: 우빈 | 파트: 임베디드 / 향 분류

---

## 1. 지금까지 vs 앞으로 (한 장 요약)

지금까지는 센서 회사(보쉬)가 주는 프로그램 **BME AI-Studio**로 향을 학습시켰어요.
"우디향 vs 그냥 공기" 2개 구분해서 정확도 96%까지 뽑았습니다. 여기까진 성공.

그런데 문제가 하나 있어요. **AI-Studio는 최대 4종류까지만 구분할 수 있습니다.**

우리가 하고 싶은 건 이거잖아요:
> 향 3가지 + 섞인 향 + 악취 + 그냥 공기 = **6종류 이상**

그래서 보쉬 프로그램을 빼고, **분류하는 인공지능을 우리가 직접 만들기로 했습니다.**
이미 코드는 다 짜놨고, 가짜 데이터로 끝까지 돌아가는 것 확인했어요.

## 2. 원리를 쉽게 설명하면: 소믈리에

BME688 센서는 냄새를 맡을 때 내부 히터로 온도를 **10단계로 바꿔가며** 측정합니다.
와인 소믈리에가 온도 바꿔가며 10번 음미하는 것과 같아요.

핵심은, **냄새마다 반응하는 온도가 다르다**는 것.
그래서 10개 숫자를 나란히 놓으면 그 냄새만의 "지문"이 됩니다.

```
우디향:   ▂▃▅▆▇▇▆▅▃▂   ← 낮았다가 치솟는 모양
시트러스: ▅▅▄▃▂▂▃▄▅▅   ← U자 모양
```

이 지문 데이터는 원래부터 우리 손에 있었어요.
지금까지는 이걸 보쉬의 "채점관"(AI-Studio)에게 맡겼는데, 채점관이 "4명까지만 구분해줄게"라고 하니까 — **채점관을 우리가 직접 키우는 겁니다.** 지문만 있으면 몇 종류든 구분 가능.

## 3. 우리가 만든 것 (3단계)

| 단계 | 프로그램 | 하는 일 | 비유 |
|---|---|---|---|
| ① 지문 뽑기 | parse_bmerawdata.py | 센서 기록에서 지문(10개 숫자)만 추출 | 재료 손질 |
| ② 학습 | train_scent.py | "이 지문은 우디, 이건 시트러스" 반복해서 가르침 | 채점관 훈련 |
| ③ 실전 | infer_jetson.py | 젯슨에서 실시간으로 "지금 우디향 87%!" 방송 | 채점관 출근 |

②에서는 인공지능 방식 6가지를 자동으로 겨루게 해서 **제일 잘 맞추는 놈을 뽑아 씁니다.** (이 비교표는 최종 보고서에 그대로 들어갈 재료이기도 해요)

## 4. 이게 왜 우리 프로젝트의 세일즈 포인트인지

1. **클래스 무제한**: 향 종류를 늘리고 싶으면 데이터만 더 모으면 됨. 프로그램 제한 없음
2. **"직접 만들었다"**: 남의 툴 버튼만 누른 게 아니라 학습 파이프라인을 자체 구축 — 심사 때 기술력 어필 포인트
3. **역할 분담이 예쁨**: 센서(ESP32)는 1차로 간단히 거르고, 두뇌(젯슨)가 정밀 분류
   → "엣지 + 허브 하이브리드"라는 그럴듯한 스토리가 됨
4. **섞인 향 판정**: 채점관이 "우디 50% / 시트러스 45%"처럼 헷갈려하면 → "아, 섞였구나"로 판단. 사람이 애매한 냄새 맡을 때랑 같은 원리

## 5. 점수를 정직하게 재는 장치 (중요해서 따로 설명)

인공지능 점수는 잘못 재면 **가짜로 높게** 나옵니다.

같은 날 연속으로 찍은 데이터는 거의 쌍둥이라서, 이걸 반 갈라 "반은 공부, 반은 시험"을 치면 시험지에 방금 본 문제가 나오는 셈이에요. 96점이 나와도 실력이 아닙니다.

그래서 우리는 **"녹화 세션 통째로" 갈라서, 한 번도 본 적 없는 날의 데이터로만 시험**을 치게 만들었어요. 이 점수가 발표 데모날에도 나올 진짜 점수고, 보고서에 쓸 숫자도 이겁니다.

## 6. 앞으로 할 일

1. **검증**: 이미 있는 우디/공기 데이터로 우리 채점관 점수 측정 → 보쉬 96%랑 비슷하게 나오면 통과
2. **수집**: 새 향들 데이터 모으기 — 향 하나당 20분짜리 녹화 3번 이상, 거리/농도 바꿔가며
3. **학습 + 실전 연결**: 6종류 학습 → 젯슨에 올려서 실시간 데모

## 7. 팀에서 도와줬으면 하는 것

- **데이터 수집 알바(?)**: 향 종류당 20분 × 3세션이라 손이 좀 갑니다. 녹화 세팅은 제가 다 해두고, "시간 되면 향 놓고 켜기 / 끝나면 끄고 환기" 정도만 나눠서 하면 금방 끝나요
- **향 종류 확정**: 발향부에서 쓸 향이랑 같은 걸로 학습해야 해서, 향 3가지는 빨리 정할수록 좋습니다
- **악취 소스 아이디어**: "나쁜 냄새 감지 → 공기청정 가동" 데모용. 단, 알코올 들어간 건 안 됨 (센서 교란)
